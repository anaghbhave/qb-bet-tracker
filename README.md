# QB Bet Tracker

A shared 2026 season tracker comparing Jayden Daniels and Dak Prescott across QBR, passer rating, total touchdowns, touchdown-to-interception ratio, and team wins.

## Run locally

```bash
npm install
npm run dev
```

Use `npm test` to build and verify the site. Shared scoreboard data is stored in D1, and ESPN requests run through same-origin API routes.
